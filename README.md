# Tantrāloka — private study copy

Private repository. Not for redistribution.

- `book/Tantraloka-Vol1-Ch1-Dyczkowski.epub` — *Tantrāloka: The Light On and Of the Tantras*, Volume One, Chapter One,
  by Abhinavagupta, translated by Mark S. G. Dyczkowski (2023). The epub contains the book as 514 page images
  (open it in any epub reader). © the translator / publisher; kept here for personal study only.
- `text/Tantraloka-Vol1-Ch1-Dyczkowski.txt` — the full text of the same book, extracted from all 514 page images by OCR
  (English and Devanagari). Each page image is marked `[image NNN of 514]`. Romanised Sanskrit loses some diacritics
  in OCR, and Devanagari has occasional misread conjuncts; check the epub page image where exact wording matters.

The Sanskrit text of Āhnika 1 with Jayaratha's Viveka, and an independent English rendering of the verses,
are on the public Sanskrit Depository site.
